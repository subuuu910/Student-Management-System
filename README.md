# Student Management System

A console-based Student Management System developed using C++ with File Handling.

## Features
- Add Student
- Update Student Details
- Delete Student Records
- Display Student Records
- Save student information in a text file
- Load saved records when the program starts

## Technologies Used
- C++
- File Handling
- VS Code
- MinGW GCC Compiler

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
g++ main.cpp -o student
```

5. Run the program:

```bash
.\student.exe
```
